# Project report outline

1. **Title page**: project title, name, roll number, department, guide, date
2. **Abstract** (150 words)
3. **Introduction**: problem, motivation, objectives
4. **Literature survey**: existing tracking apps, courier SMS systems, text information extraction, delay prediction
5. **System design**: architecture diagram, data flow, database schema (see `docs/ARCHITECTURE.md`)
6. **Methodology**
   - Message parsing (regex baseline, then NLP model)
   - Dataset (simulated, then real) and features
   - Models compared and evaluation metrics (accuracy, precision, recall, F1, confusion matrix)
7. **Implementation**: technologies, modules, key screenshots
8. **Results and discussion**: parser accuracy (`evaluate_parser.py`), model comparison table, example alerts
9. **Testing**: unit tests, sample runs
10. **Limitations and future work**
11. **Conclusion**
12. **References**
